# 🔍 Поиск мастеров маникюра в Telegram

## Быстрый старт

### Шаг 1 — Установите Python
Скачайте Python 3.10+ с https://python.org
При установке на Windows отметьте галочку "Add to PATH"

### Шаг 2 — Установите зависимости
Откройте терминал в папке с файлами и выполните:

    pip install -r requirements.txt

### Шаг 3 — Получите API-ключи
1. Перейдите на https://my.telegram.org
2. Войдите под своим номером телефона
3. Откройте раздел "API development tools"
4. Создайте приложение (название и платформа — любые)
5. Скопируйте "App api_id" (число) и "App api_hash" (строка)

### Шаг 4 — Настройте скрипт
Откройте файл manicure.py и замените в блоке КОНФИГУРАЦИЯ:

    API_ID   = 12345678       # ← вставьте ваш api_id (число, без кавычек)
    API_HASH = "abcdef1234"   # ← вставьте ваш api_hash (строка, в кавычках)

    TARGET_CHATS = [
        "@username_чата_1",
        "@username_чата_2",
        "@username_чата_3",
    ]

### Шаг 5 — Запустите

    python manicure.py

### Шаг 6 — Авторизация (только первый раз)
Скрипт попросит ввести номер телефона и код из Telegram:

    Please enter your phone: +79991234567
    Please enter the code:   12345

После этого создастся файл manicure_session.session — повторно вводить данные не нужно.

---

## Результат
По завершению в папке появится файл masters.txt со списком @username мастеров.

---

## Настройки (в файле manicure.py)

| Параметр         | По умолчанию | Описание                              |
|------------------|--------------|---------------------------------------|
| MESSAGES_LIMIT   | 5000         | Сколько сообщений сканировать в чате  |
| DELAY_MIN/MAX    | 6–10 сек     | Задержка между запросами профилей     |
| CHAT_PAUSE_MIN/MAX | 30–60 сек  | Пауза между чатами                    |
| BIO_KEYWORDS     | см. список   | Ключевые слова для поиска в Bio       |

---

## Частые проблемы

pip не найден         → попробуйте: pip3 install -r requirements.txt
python не найден      → попробуйте: python3 manicure.py
API_ID invalid        → убедитесь, что api_id — число БЕЗ кавычек
Chat not found        → проверьте правильность @username чата
SESSION_NAME ошибка   → удалите файл manicure_session.session и запустите снова
